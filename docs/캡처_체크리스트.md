`docs/captures/` 에 아래 파일명 **그대로** 저장하면 보고서 빌더가 자동으로 넣습니다.

## 준비 — 한 번만 하면 됩니다

1. **터미널 글자를 줄입니다.** `Cmd` + `-` 를 3~4번. 6단계는 71줄이라 안 줄이면 한 화면에 안 들어갑니다.
2. **터미널 창을 세로로 최대한 키웁니다.** (초록 버튼 대신 아래 모서리를 끌어서)
3. 프로젝트 폴더에서 가상환경을 켜고 실행합니다.

```bash
cd ~/projects/skala-workspace/skala-python-part2
source .venv/bin/activate
python main.py
```

약 18초면 끝납니다. **한 번만 돌리고 스크롤을 올려가며** 7장을 찍으면 됩니다.

## 찍는 방법

- `Cmd` + `Shift` + `4` → 드래그해서 영역 선택 (배경 없이 깔끔)
- 또는 `Cmd` + `Shift` + `4` → `Space` → 창 클릭 (창 전체, 그림자 포함)

둘 중 편한 쪽으로 하시되 **7장 모두 같은 방식**으로 통일하는 게 보기 좋습니다.
