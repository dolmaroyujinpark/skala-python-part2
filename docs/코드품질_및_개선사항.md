## 4. 개선 제안

### 4-1. 통계 검증력 강화 — 효과 크기

표본이 280만 건이라 p-value가 항상 0에 수렴합니다. Cohen's d를 추가하세요.

```python
# stats_test.py run_ttest() 반환 dict에 추가
import numpy as np

n1, n2 = len(a), len(b)
pooled_var = ((n1 - 1) * a.std()**2 + (n2 - 1) * b.std()**2) / (n1 + n2 - 2)
cohens_d = (a.mean() - b.mean()) / np.sqrt(pooled_var)

# 결과에 추가
"Cohen's d": round(float(cohens_d), 4),
```

해석 기준:
- `|d| < 0.2` : 무시할 수준
- `0.2 ≤ |d| < 0.5` : 작은 효과
- `0.5 ≤ |d| < 0.8` : 중간 효과
- `|d| ≥ 0.8` : 큰 효과
