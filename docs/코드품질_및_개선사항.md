### 4-1. 통계 검증력 강화 — 효과 크기(Cohen's d)

**배경** : 표본이 280만 건이라 p-value가 항상 0에 수렴합니다. p-value만으로는 효과의 실질적 크기를 알 수 없으므로 Cohen's d를 함께 제시해야 합니다.

**해석 기준**:
| `|d|` | 의미 |
|---|---|
| < 0.2 | 무시할 수준 |
| 0.2 ~ 0.5 | 작은 효과 |
| 0.5 ~ 0.8 | 중간 효과 |
| >= 0.8 | 큰 효과 |

**적용 파일** : `src/stats_test.py` — `run_ttest()` 함수

**구현 코드**:

```python
import numpy as np

# run_ttest() 내부, t-test 수행 후 추가
n1, n2 = len(a), len(b)
pooled_var = ((n1 - 1) * a.std() ** 2 + (n2 - 1) * b.std() ** 2) / (n1 + n2 - 2)
cohens_d = (a.mean() - b.mean()) / np.sqrt(pooled_var)

# 반환 dict에 추가
{
    ...,
    "Cohen's d": round(float(cohens_d), 4),
    "효과 크기": _interpret_cohens_d(cohens_d),
}
```

```python
# common.py 에 해석 헬퍼 추가
def _interpret_cohens_d(d: float) -> str:
    """Cohen's d 값을 해석 문구로 변환한다."""
    d_abs = abs(d)
    if d_abs < 0.2:
        return "무시할 수준"
    if d_abs < 0.5:
        return "작은 효과"
    if d_abs < 0.8:
        return "중간 효과"
    return "큰 효과"
```

**report.md 반영** : `_section_stats()` 에서 각 t-test 결과에 Cohen's d 해석 추가.

**예상 결과**:
- 정체/비정체 거리 차이: `|d| ≈ 0.6~0.8` (중간~큰 효과)
- 주말/평일 속도 차이: `|d| ≈ 0.2~0.3` (작은 효과)
- 출퇴근/비출퇴근 속도 차이: `|d| ≈ 0.15~0.20` (작거나 무시할 수준)

# model.py train_and_evaluate() 결과 dict에 추가
def _extract_feature_importance(pipeline: Pipeline) -> pd.DataFrame:
    """Pipeline에서 피처 중요도를 추출한다."""
    rf = pipeline.named_steps["classifier"]
    preprocessor = pipeline.named_steps["preprocess"]
    feature_names = preprocessor.get_feature_names_out()
    importances = rf.feature_importances_

    df = pd.DataFrame({
        "피처": feature_names,
        "중요도": importances,
    })
    return df.sort_values("중요도", ascending=False).head(20)

```python
import shap

# train_and_evaluate() 함수 내, 모델 학습 후 추가
def _shap_analysis(pipeline, x_train, x_test):
    """SHAP TreeExplainer로 피처 기여도를 분석한다."""
    explainer = shap.TreeExplainer(pipeline.named_steps["classifier"])

    # 전체 데이터셋 요약 (500건 표본)
    transformed = pipeline.named_steps["preprocess"].transform(x_test[:500])
    feature_names = pipeline.named_steps["preprocess"].get_feature_names_out()
    shap_values = explainer.shap_values(transformed)

    # summary plot 저장
    shap.summary_plot(
        shap_values[:, :, 1],  # 정체 클래스에 대한 SHAP
        transformed,
        feature_names=feature_names,
        show=False,
        max_display=20,
    )
    plt.title("SHAP 피처 기여도 — 정체 예측", fontsize=14)
    plt.tight_layout()
    plt.savefig(FIGURE_DIR / "07_shap_summary.png", dpi=150, bbox_inches="tight")
    plt.close()
```

### 4-5. GridSearchCV 하이퍼파라미터 튜닝

**배경** : 현재 `n_estimators=100, min_samples_leaf=5`는 경험적 선택입니다. GridSearchCV로 체계적인 탐색을 하면 추가 성능 향상이 가능합니다. Pipeline 구조이므로 `classifier__` prefix로 파라미터를 지정할 수 있습니다.

**적용 파일** : `src/model.py`

**구현 코드**:

```python
from sklearn.model_selection import GridSearchCV

# train_and_evaluate() 함수 내, RandomForestClassifier 생성 전
param_grid = {
    "classifier__n_estimators": [100, 200],
    "classifier__max_depth": [None, 15, 30],
    "classifier__min_samples_leaf": [3, 5, 10],
    "classifier__class_weight": ["balanced", "balanced_subsample", None],
}

grid = GridSearchCV(
    pipeline,
    param_grid,
    cv=3,
    scoring="f1_macro",
    n_jobs=-1,
    verbose=1,
)
grid.fit(x_train, y_train)
pipeline = grid.best_estimator_

# 결과 dict에 추가
{
    ...,
    "best_params": grid.best_params_,
    "best_score": float(grid.best_score_),
}
```

**예상 결과**: `min_samples_leaf=5`는 이미 최적값에 가까울 가능성이 높습니다. `max_depth=None`(기본값)이 가장 좋거나, 과적합 시 15~30 사이에서 최적이 나올 수 있습니다. `class_weight='balanced'`는 불균형 데이터(33:67)에서 재현율을 개선할 수 있습니다.
